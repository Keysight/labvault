# Concepts

| Term | Meaning |
|------|---------|
| Device | Generic managed node |
| Keysight chassis | Hardware chassis record (Ixia/Keysight family) |
| Lab topology | Designer graph for a lab (nodes, links, scenarios) |
| Fabric | Port-level connectivity / snapshots on a topology |
| Reservation | Time-bounded ownership |
| Fleet API | Bearer JSON automation under `/api/fleet/*` |
| Workers | heartbeat / collector / refresh — default **idle** |
| opsd | Allowlisted service controller on a Unix socket |
| LabVault CLI | Staff console + `/api/cli/v1/*` |
| Dual DB | `default` + `np_timeseries` |
