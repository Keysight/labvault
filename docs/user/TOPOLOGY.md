# Topology

## Topology map

`/topology/` — high-level connectivity map for the lab.

## Lab topology designer

`/lab-topology/*` supports:

- List / create / edit topologies
- Onboard inventory onto a canvas
- Test-setup and scenario definitions
- Portmap
- Links into fabric and usage insights

## CLI

`topo list`

## Tips

Start with a single topology per physical lab. Attach devices/chassis before drawing fabric so port pickers stay meaningful.
