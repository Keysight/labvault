# Reservations

Time-bounded claims on chassis and related resources.

| Surface | Path |
|---------|------|
| UI | `/keysight/reservations/*` |
| Fleet list | `GET /api/fleet/reservations.json` |
| Fleet create | `POST /api/fleet/reservations` |

Use reservations so ownership, conflict, and SLA views stay accurate across teams. Staff should prefer UI or fleet API over ad-hoc spreadsheet tracking.
