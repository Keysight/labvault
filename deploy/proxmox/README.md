# Proxmox guest notes

Create a generic Ubuntu or Rocky guest (4 vCPU / 8 GiB / 40 GiB), then run a
oneshot **inside the guest**. See [../../docs/install/PROXMOX.md](../../docs/install/PROXMOX.md).

Do not bake a specific lab VMID or management IP into this tree.
