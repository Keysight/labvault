# Contributing

Issues are welcome. External PRs are reviewed only after Keysight confirms the
DCO/CLA policy for this repository.

1. Fork / branch from `main`
2. Keep changes scoped to retained public features
3. Run `python manage.py test`, `python tools/check_public_source.py`, and `python tools/check_docs.py`
4. Do not reintroduce Capex, Hyperview, LAAS, AI Nexus, Snappi, Demo Stage, or UHD hardware
